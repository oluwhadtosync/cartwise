AI Deal Discovery

About Cartwise

Built for the PayPal AI Hackathon 2026 on Devpost. Cartwise solves cross-border e-commerce by executing headless browser checkouts with escrow buyer protection.

Official Hackathon Submission

Cloud Architecture

  • PayPal Sandbox: Orders v2 (AUTHORIZE)
  • Google Gemini 3.8: Landed Cost Reasoning
  • Kernel: Isolated Playwright Sessions
  • Channel3: Multi-Store Product Index
  • Render: Hosted Blueprint Microservices

Security & Safeguards

  • $0 Upfront Risk: Hold only, not charged
  • Auto-Void Safeguard: Reverts hold if decline
  • Zero Card Exposure: Merchant never gets card
  • AI Risk Scoring: Domain security analysis
